## 2. 核心观测结果

### 2.1 模型对齐：DM 逐对总量 vs 官方参照

| 对象 | 原始值 | 整数输出 | 相对官方参照 (52) Q-error | 相对 $C_{DM}$ (5) Q-error |
| --- | ---: | ---: | ---: | ---: |
| 官方参照（`gpt-5.4-nano`） | 52 | 52 | 1.000 | 10.400 |
| DM 逐对硬标签总量 $C_{DM}=\sum_e \mathbf{1}[p_e \ge 0.5]$ | 5.000 | 5 | **10.400** | 1.000 |
| DM 逐对软分数总量 $\sum_e p_e$ | 17.658 | 18 | 2.945（整 2.889） | 3.532（整 3.600） |
| 状态聚合代理总量 $M=\sum_e \mu_e$ | 39.037 | 39 | 1.332（整 1.333） | 7.807（整 7.800） |

- **逐对概率分布（观测事实）**：100 对的 $p_e$ 强烈偏向 0——最小值 `0.0180`、Q25 `0.0651`、中位数 `0.1115`、Q75 `0.2273`、最大值 `0.7583`。分桶计数：`[0, 0.1)` 43 对、`[0.1, 0.2)` 28 对、`[0.2, 0.3)` 10 对、`[0.3, 0.4)` 8 对、`[0.4, 0.5)` 6 对、`[0.5, 1.0]` 仅 5 对。
- **解释边界**：本地没有 `gpt-5.4-nano` 的逐对标签，无法判断两模型谁更准确，只能确认二者在 Q63 sf10 上的判定松紧尺度相差一个数量级。纯代理 $M=39.04$ 相对官方 52 的 Q-error 较低（1.33），属于高估背景分带来的总量巧合，不能视为配对对齐。

### 2.2 表示能力：代理 $\mu_e$ 能否解释 DM 逐对变化

| 指标 | $\mu_e$ vs 硬标签 $Y_e^{DM}$ | $\mu_e$ vs 软分数 $p_e$ |
| --- | ---: | ---: |
| 目标均值 / 代理均值 | 0.050 / 0.390 | 0.177 / 0.390 |
| 目标样本方差 $S^2$ | 0.04798 | 0.02622 |
| 残差方差 $S^2_{Y-\mu}$ | 0.06649 | 0.03932 |
| **方差比 $S^2_{Y-\mu}/S^2_Y$（固定 $\lambda=1$）** | **1.3859（方差 +38.6%）** | **1.4995（方差 +50.0%）** |
| 协方差 / Pearson $r$ | -0.00426 / **-0.1946** | -0.00155 / **-0.0960** |
| 逐对 RMSE / MAE | 0.4262 / 0.4098 | 0.2909 / 0.2618 |
| 全矩阵诊断上限 $\lambda^*$（不可部署） | $\lambda^*=-0.4264$，方差比 0.9621 | $\lambda^*=-0.1555$，方差比 0.9908 |

- **观测结论（负面结果）**：当前手工状态构造的 $\mu_e$ 与 $Y_e^{DM}$ 呈弱负相关，固定 $\lambda=1$ 残差纠偏使抽样方差上升 38.6%；即使事后使用不可部署的全矩阵最优系数 $\lambda^*$，方差也几乎无法下降。
- **根因诊断（结合行状态、$K$ 与配对失败案例）**：
  1. **状态覆盖塌缩进 `other`**：左侧 10 件商品在 `[paper, textile, other]` 上的平均概率为 `[0.1043, 0.1109, 0.7848]`，8/10 件商品的 `other` 概率在 79.4%–99.7%；右侧 `[paper, textile, multi, other]` 平均为 `[0.3283, 0.0363, 0.1961, 0.4393]`。
  2. **`other` 桶获得偏高背景兼容分**：$K[\text{other}, \cdot] = [0.4550, 0.3626, 0.4006, 0.2685]$，把大量无关配对抬高到 0.27–0.49。
  3. **材料与工具角色混淆**：商品 5（浮雕模板/刀模，本质为工具）在左侧被判 `paper=0.663`、右侧 `paper=0.973`，导致自连接 `(5,5)` 获得全场最高代理分 $\mu=0.725$，而 DM 逐对判定 $p=0.064, Y=0$（残差 `-0.725`）；类似还有 `(5,8)`（$\mu=0.664, Y=0$）和 `(4,4)`（$\mu=0.652, Y=0$）。
  4. **DM 判正的 5 对全部被代理低估**：`(4,5)` 丝带 → 刀模（$p=0.661, \mu=0.136$，残差 `+0.864`）、`(4,1)` 丝带 → 马克笔（$p=0.729, \mu=0.216$，残差 `+0.784`）、`(0,9)` Drawing Kit → 画笔套装（$p=0.758, \mu=0.340$，残差 `+0.661`）、`(6,2)` 玻璃灯工材料 → 透光描图板（$p=0.561, \mu=0.402$，残差 `+0.599`）、`(8,2)` Crayola 蜡笔 → 透光描图板（$p=0.643, \mu=0.437$，残差 `+0.563`）。

## 3. 结论与下一步行动（按方案第 8 节）

本轮同时触发了方案第 8 节的三条“先修方法，暂不扩大到 sf100 或新查询”条件，因此**不启动 sf100 或留出查询实验**。后续研究应优先隔离并解决两个独立问题：

1. **DM 逐对提示与校准诊断**：当前 `noul` 将 Q63 谓词与商品描述一并放入 `input`，而 `instructions`/`criteria` 仅为泛化占位句；需在受控小样本上检验将谓词结构化放入 `instructions`/`criteria` 是否影响概率尺度，并厘清 `gemini-decision-1` 与 `gpt-5.4-nano` 的语义口径差异。
2. **行级状态表示重构**：将“是否属于材料 / 工具本身”与“工艺门类”解耦，避免工具类商品误归入材料状态，并抑制 `other` 桶的高背景兼容分；仅当新版本状态在小切片上验证出稳定正相关与方差下降后，再讨论扩大规模与留出集验证。
