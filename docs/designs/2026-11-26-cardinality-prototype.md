# 低成本语义基数估计原型：catalog、检索统计与预算内抽样

日期：2026-11-26。状态：基于讨论整理的原型设计草案；未实现，未冻结正式实验配置，未验证精度或收益。

## 1. 定位与设计取舍

本原型为语义查询优化提供 filter / join 的输出规模预测。基数估计是整体框架的辅助模块，优先使用低成本、可维护的 catalog 和普通检索计算，不将训练一个高泛化深度基数模型作为前置要求。

讨论形成的方向是：入库时维护查询无关统计；查询到来后，尽量用一次结构化解析把条件映射到已有统计与检索操作；必要时检查少量真实记录或配对，形成预算内估计。一次解析是优化目标，不是任意查询、catalog 大小和服务接口下的保证。

第一版采用以下范围：

- 文本单表 filter、双输入 semantic join；输出基数，不枚举完整结果。
- 不新增模型训练，不逐行调用 LLM 构建完整语义表示。
- 核心 catalog 为按字段倒排索引、词汇与属性统计、稳定行身份和原文入口；已有向量与代表样本为可选增强。
- 严格区分检索代理、固定标签下的抽样估计、相对另一参照模型的预测。
- 先采用固定预算与冻结分层；是否采样、采哪里以及动态停止留作受控扩展。
- 不创建新实验工程、不启动正式实验；任务、切片、参照、预算和指标须另行确认并冻结。

### 与现有文档的关系

[整体优化框架](../discussions/2026-11-24-dm-semantic-query-optimization-framework.md)定义联合选择执行顺序与调用组织的研究方向；本原型提供其中的估计接口，不替代规划器或执行器。

[旧 DM primitive 原型](2026-11-23-dm-primitives-semantic-join-design.md)重点探索事件分数、联合状态、等级和兼容矩阵的聚合。本方案改用词汇、检索统计和抽样作为近期主路径，不自动采用旧文档的一次调用固定成本、理想判定等假设，也不修改旧稿。

[Q63 小切片诊断](../experiments/semceb-dm-small-slice-diagnostic/2026-11-23-semceb-dm-small-slice-diagnostic-results.md)已经观察到当前手工状态代理与 DM 标签弱负相关、纠偏方差增加。该结果支持继续隔离判定与估计问题，不能支持本方案有效，也不能据此确认 instruction 是失败主因。

## 2. 任务契约与估计目标

查询契约包括：数据快照、表及别名、稳定行身份、允许字段、原始自然语言谓词、参数方向、候选域规则、缺失信息约定和参照判定协议。

过滤目标为：

$$
C_F=\sum_{r\in R}Y_F(r),\qquad N_F=|R|.
$$

连接目标为：

$$
C_P=\sum_{(r,s)\in\Omega_P}Y_P(r,s),\qquad N_P=|\Omega_P|.
$$

默认全连接时 $\Omega_P=R\times S$。自连接保留有序配对和对角线，除非查询另有要求；相同文本的不同记录仍分别计数。不擅自添加商品—评论外键连接，不用向量相似度定义参照标签。

参照判定与样本标签来源分别记录。使用 DM 标签时，抽样估计针对冻结的 DM 判定总量；不能宣称它对官方参考模型的总量无偏。将模型概率求和与将固定二元标签抽样外推分开报告。

输入为空时直接返回 0。查询不能解析或预算不足时返回明确的回退／不支持状态，不用零伪装失败。

## 3. 查询无关 catalog

### 3.1 核心内容

| 组件 | 保存什么 | 用途与成本边界 |
| --- | --- | --- |
| 行与字段目录 | 行 ID、字段类型、缺失情况、原文定位、数据版本 | 固定人口与证据范围；不复制不必要的长文本 |
| 字段倒排索引 | token / 短语到行 ID 的 posting，文档频率、词频、长度统计 | 集合交并、计数与 BM25；记录分词、大小写和规范化版本 |
| 廉价属性统计 | 可确定解析的 JSON 键、数值、单位、类别及缺失／歧义状态 | 高频值和范围分桶；不把未经验证的语义提取当精确属性 |
| 成员访问接口 | 分组行 ID、人口数、按随机位置访问记录的能力 | 对查询相关区域抽样，避免逐条模型扫描 |
| 可选样本 | 固定种子维护的随机样本，及单独标记的代表样本 | 随机样本支持统计；代表样本仅描述区域，不能冒充随机样本 |

优先复用常规 tokenization、关键词提取和 JSON 解析。无需先训练一套可解释的完整语义关系；属性、词汇和角色线索只有在具体估计路径使用时才值得增加。

### 3.2 可选增强

SemCEB 已提供按字段的 Qwen / SigLIP2 向量。可复用它们建立近邻或少量分组，不要求重新编码全表。向量、近邻图与分组的存储和建设成本仍需计量。

若需要可读桶描述，可以对抽样短语／代表样本进行少量离线 LLM 分析，生成主题名及线索。该操作只用于查询对齐和分层，不赋予桶成员语义一致性的保证。单纯固定词汇索引路径不依赖此步骤。

不同语义标签可以重叠；实际抽样分区必须互斥。catalog 保留行身份与部分联合信息，不只保存各列边缘频率。主题、角色或字段分别成立，不推出其合取成立。

### 3.3 维护与版本

第一版目标为追加数据：更新 postings、词频、长度、人口和受影响属性桶；若启用随机样本，使用记录算法与种子的维护方法。删除、字段修改可先通过重建受影响结构处理，暂不承诺完整实时增量索引。

分词、提取、向量、分组或模型版本变化时，相应结构应重建或显式迁移。在线新增关键词扩展或属性提取不能因为写回 catalog 就转成免费离线成本。

catalog 必须与当前输入切片匹配。全表频数不能直接用于任意子集；已有幸存行 ID 时可重新交并和汇总，但未知中间关系及其重数估计不在第一版范围。

## 4. 查询解析与统计访问

### 4.1 结构化输出

解析器读取原查询和受限大小的字段／catalog 描述，输出：

| 字段 | 含义 |
| --- | --- |
| `operator`、`bindings`、`allowed_fields` | filter / join、别名、参数顺序及字段权限 |
| `original_predicate`、`conditions` | 保留原文；表示合取、析取、否定、比较与条件间关系 |
| `lexical_probes` | 关键词、短语、同义扩展和字段范围，仅为检索线索 |
| `attribute_probes` | 可访问的数值、类别和范围统计 |
| `left_probes`、`right_probes`、`residual_relation` | join 的单侧角色线索及不能单侧解释的关系 |
| `unresolved` | catalog 未覆盖、解析歧义和需要原文判断的部分 |

解析结果经过确定性校验：字段是否越权、别名是否存在、左右方向是否保留。失败时退回原谓词上的均匀抽样。可预留预算内一次修复，但不无限重试。

优先确定性解析已有结构；需要自然语言理解时目标为一次模型请求。若完整 catalog 超出上下文，先廉价检索少量相关描述；记录选择范围，保留未覆盖标记。模型可读全局字段名，但不得以未被查询允许的行级字段补充判定证据。

### 4.2 Q63 示例

Q63 可分解为“左侧主要提供材料”“右侧主要提供工具”“右侧工具可以用于左侧材料”。材料词、工具词和工艺词用于划分采样区域；第三项保留为成对关系。

不能把“材料命中行数 × 工具命中行数”当作真实基数；不能把“用于加工纸张”的工具视为纸张材料；多角色记录允许同时命中多个线索。

### 4.3 BM25 的职责

BM25 为相关性排序与分层提供信号，不输出成立概率。明确词汇条件优先使用 posting 的集合交并与计数，不必为每次访问计算 BM25。

不得把 top-k 返回量当作基数，不使用未经校准的跨查询统一分数阈值宣称语义计数准确。若使用高／低分区域，阈值规则在评测前冻结，不能查看测试真值后选择。

宽泛词汇的 posting 扫描、全量评分和在线分桶仍可能昂贵。记录扫描量和实际耗时；预算受限时退回廉价命中／未命中分区，而非强制全表 BM25 打分。

## 5. 两种输出模式

### 5.1 仅 catalog 的代理模式

通过词汇集合运算、属性频数或简单规则输出 `proxy_estimate`。例如词汇命中数、规范化属性频数连接数，或 Q63 左右命中区域的乘积。它们是声明明确的代理计算，不保证等于参照语义基数；上述乘积也不保证是参照结果的上界。

能确定等价实现原谓词时才直接给出精确计数；对 SemCEB 参考模型，逻辑上合理的规则也不自动与其判断等价。无法形成有依据的数值代理时允许返回未知，由下述抽样模式处理，不凭空指定成立率。

此模式用于最低成本对照或启发式规划。输出其适用规则、未解决条件、`interval=null` 和校准状态，不产生虚假的置信度。

### 5.2 catalog 辅助的固定预算抽样模式

将允许候选域划成少量互斥、完整覆盖的层 $H_h$，人口为 $N_h$。冻结分层和样本量，在每层均匀无放回抽取 $b_h$ 个候选，按固定协议判断：

$$
\widehat C=\sum_h N_h\overline Y_h,
\qquad
\overline Y_h=\frac{1}{b_h}\sum_{e\in A_h}Y(e).
$$

在固定二元标签、正确人口、完整分区和上述采样设计下，该估计对相应标签总量设计无偏。检索不完美主要影响方差；低分与未命中区域仍有抽样机会，因此不是免费判零。模型判定误差不包含在这项无偏性结论中。

初版按层大小分配预算，确保每个非空层有样本；层太多时先合并，必要时退回全局均匀抽样。至少一个样本可定义点估计，但不足以可靠估计层内方差。预算不足以完成约定设计时回退或返回预算不足，不将未完成层当作零。

第一版不使用主样本标签调分层、调阈值、选择纠偏系数或提前停止。若后续引入先导阶段，其成本计入预算，主样本设计另行冻结。

## 6. Filter 路径

1. 按允许字段检索词汇／属性线索。
2. 构造少量区域，例如强线索命中、弱线索命中、其余。最简单实现只区分命中与未命中。
3. 用集合差消除重叠，核对各层人口之和等于输入行数。
4. 从完整成员集合随机抽样，读取原谓词要求的原文，取得标签并加权汇总。

数值／类别条件优先采用廉价解析和属性桶；否定和信息缺失条件保留原语义。“明确不适合儿童”不能变成“不含儿童关键词”，“未提及”不能与提取失败混为一类确定结论。

多字段条件在同一行上进行集合与联合特征操作，不把边缘选择率直接相乘。仅使用有限离线样本时，记录其采样设计和多阶段误差；不将样本命中率当作精确桶人口。

## 7. Join 路径

### 7.1 默认：记录分组后的配对抽样

第一版以直接候选配对抽样为基础。左右分别构造少量互斥行组 $R_a,S_b$，配对块为 $R_a\times S_b$；默认全连接时人口为 $|R_a||S_b|$。在块内均匀抽配对，使用第 5.2 节估计器。

通过成员列表和整数位置采样，不显式枚举笛卡尔积。自连接左右角色可不同；对角线保留。若候选域另有限制，必须重新实现对应人口与均匀抽样，不能沿用乘积人口。

Q63 可以各侧按角色词汇命中／未命中划为两组，最多形成四个配对块；Q87 可按耗材与适配线索分区。所有块均被覆盖，不把其余块排除。属性相等连接可另报频数乘积代理；未知值不能统一当作一个可相等属性值。

此路径避免给每条左记录分别发起右表检索，但不能保证解决稀疏阳性问题：左右角色分组可能仍不能区分真正适配关系，需以实测误差判断是否值得。

### 7.2 候选扩展：借鉴 SemStats 的 join 转 filter

从 $R$ 均匀抽取 $b_R$ 条记录。对每个 $r$，构造保持原始语义的条件化过滤问题 $F_r(s)=P(r,s)$，调用 filter 估计器得到 $\widehat C_r$，再计算：

$$
\widehat C_{\mathrm{join}}
=\frac{|R|}{b_R}\sum_{r\in A_R}\widehat C_r.
$$

优先通过模板绑定左侧原文实现条件化，不需要每次生成新的自然语言摘要。确需 LLM 改写时，逐样本或批量改写的请求、token 与语义检查均计入在线成本；不能称为全查询只调用一次。

仅当内层估计相对 $P(r,s)$ 正确、外层抽样符合设计时，才能给出相应抽样性质；改写语义误差、内外层抽样波动和 judge 偏差需分别考虑。稀有高连接度左记录可能被漏采，区间也不能只报告内层误差。

该路径作为后续对照，不与默认路径同时复杂化。先比较条件化访问是否确实减少统计与判定成本，再决定是否加入原型。

## 8. 输出、不确定性与采样决策

最小输出包含：原始实数基数估计、选择率、候选人口、输出模式、标签目标、数据与谓词版本、分层人口与样本数、预算消耗、未解决条件、回退原因。整数化或截断规则在评测前固定，保留处理前数值。

分别标记：

- 选择率：预计有多少候选成立，不等于模型自信程度。
- 抽样不确定性：针对指定采样设计和标签目标；第一版未实现可靠区间时返回空值。
- 语义可靠性：解析、索引和 judge 与参照之间的误差，不能用抽样区间代替。

小样本或全零样本不意味着精确为零，也不能因经验方差为零就返回零宽度区间。后续需选择适合有限总体与稀疏事件的区间方法；不得把 DM 分数直接解释成区间覆盖率。

第一版由调用方指定代理或固定预算抽样模式，不训练采样策略。后续允许规则或 DM 决定是否采样，其输入可以包括 catalog 覆盖、剩余预算、计划成本敏感性及已有证据。决策器本身计费。

接入优化器后，以“补充信息是否可能改变计划且值得其成本”为决策依据；若当前没有校准区间，只能使用并标记假设的敏感性范围，不能声称获得期望信息价值的可靠数值。自适应选样与停止需重新设计加权、区间与评测，不直接继承固定预算估计器保证。

## 9. 与 SemStats 的对照

### 9.1 核对范围

以下依据论文 *Bridging the Gap: Cardinality Estimation for Semantic Queries on Unstructured Data*，DOI `10.1145/3802024`。本地为 15 页作者稿，尚未确认与 ACM 26 页版本等同；本次没有审计作者代码或复现实验。[原文](../../references/papers/2026-SemStats/source.pdf)、[提取文本](../../references/papers/2026-SemStats/paper.txt)、[版本与来源](../../references/papers/2026-SemStats/provenance.json)。

### 9.2 操作与简化

| 环节 | SemStats 作者稿的操作 | 本原型的选择 |
| --- | --- | --- |
| Catalog 发现 | 抽样抽短语，默认 contextualized Top2Vec；LLM 按频率与层级识别维度（§4，页 6–7） | 借鉴压缩后分析；先建字段词汇／属性统计，层级语义树可选 |
| 维度归属 | 部分 LLM 标签训练轻量分类器，推断其余记录（§5.1，页 8） | 第一版不训练，采用词汇命中、规则与可选现成向量 |
| 维度值识别 | 近似 kNN 图筛选文档对，学习同值关系，分组赋值及 LLM 纠错（§5.1，页 8） | 暂不构建学习式同值图；需要时用简单分组及明确属性规范化 |
| 在线 judge | 索引节点组合生成查询与标签，LLM 改写表达，训练轻量 judge（§5.2，页 8–9） | 先用现有 DM 判断少量样本，训练不是前置条件 |
| 查询对齐 | LLM 将条件映射到索引约束，并分类完全满足／候选等节点（§6.1，页 9） | 借鉴结构化解析，目标一次调用；代理线索默认不触发确定排除 |
| Filter 估计 | 已满足集合计数，加候选集合的分层重要性采样估计（§6.1–6.2，页 9–10） | 默认完整覆盖总体的少量分层、层内均匀抽样；简化权重和统计实现 |
| Join 估计 | 左侧抽样；逐样本 LLM 改写右侧过滤；平均匹配数外推（§6.3，页 10） | 记录为可选扩展；默认先做少量配对块抽样 |
| 增量维护 | 小分类器匹配旧维度；相似度匹配取值，必要时 LLM 识别／新增取值（§5.1，页 8） | 先支持常规索引和统计追加；不承诺自动发现并维护完整语义维度 |

### 9.3 不应误读为“只有 kNN 和改写，没有训练”

SemStats 实验设置（§7.1，页 12）使用 10% 数据的 LLM 标签训练索引小模型：维度分类为 200 棵树的 XGBoost；维度值关系为两层 GAT 接两层 MLP，100-NN 图；实验图划分使用半监督 harmonic label propagation。方法正文另讨论谱聚类，两者不能混为同一实际配置。在线 judge 对拼接的查询—数据进行嵌入，并在 pooled representation 上接线性层；不据此推断编码器冻结或额外训练细节。

其最终计数依赖索引与抽样，不是直接训练总基数回归器。其改写既用于离线生成 judge 训练查询，也用于在线 join 转 filter，这两个用途需要区分。

作者稿给出了 join 扩展，但未展示专门的 join 定量实验；主要 filter 实验的优势不能直接推广到 SemCEB join。其主要数据集的部分测试查询由模板填值后改写，另有专家真实查询，不能据此确认任意未知谓词泛化。

### 9.4 哪些可借鉴，哪些仍需验证

可借鉴的是抽词压缩输入、查询对齐统计、分层覆盖不同区域，以及条件化 join 转 filter。语义 catalog、LLM 查询解析和分层抽样本身均为已有思想，不作为本研究独立创新主张。

SemStats 有 TF-IDF 加阈值的 Keyword baseline，以及检索 top-1% 后判断的 RAG-CE baseline（§7.1）；它们不等于 BM25，不能用其结果断言 BM25 无效。本文也不预设用 BM25 替代语义索引会保持原性能。

本原型取消训练可以减少准备环节，却可能增加在线 DM 成本或降低分层质量。SemStats 已训练的小模型推断可能很便宜；“无需训练”不是端到端更省的证据。构建、维护、在线调用与多查询摊销需分别测量。

## 10. 成本与验证计划边界

完整成本分为离线建设、数据更新、在线解析、检索／分桶、样本判断、决策与失败重试。记录请求数、逻辑判定项、输入输出 tokens、实际费用、墙钟时间、CPU／内存、索引体积、扫描量与缓存命中；不把一次请求视作恒定成本。不能取得美元成本时保留空值，不编造价格。

候选对照为：

1. 仅 catalog 的启发式代理，明确没有统计保证。
2. 全域均匀记录／配对抽样，使用相同标签协议。
3. 关键词／属性分层抽样。
4. 加 BM25 或现成向量的分层增强，分别隔离新增成本与收益。
5. SemStats 式条件化 join 转 filter，作为后续独立路径；未复现原系统前不称为 SemStats 实验对照。

正式比较还需保留官方抽基表再连接的 baseline，其行为不同于直接抽配对；不能改名互换。按相同完整预算比较，而不只固定样本判断次数。

SemCEB 先验证估计精度和在线成本，候选指标为 Q-error、偏差、RMSE、多种子波动与全零样本率；分开报告相对官方基数和相对冻结 DM 标签的误差。单条查询上代理总数碰巧接近参照，不证明其分层或配对判断正确。

解析校验、分区完整性与人口正确性、采样可复现性、固定标签小总体普查端点，是后续实现需要验证的接口性质。实际统计方法及其区间也须独立验证，不以接口测试证明估计有优势。

Q63 sf10 为已见开发切片，不能充当留出测试。查询家族、字段、数据、参照协议、种子、预算、阈值、失败处理和输出规则需预先冻结；不得根据已知缓存答案调整方法后仍称未见评测。

当前数据预览还存在需核查的分母差异：例如 sf100 总览给商品—评论人口 96,100，但 Q65 缓存 51,212 与 56.22% 对应约 91,100。原因尚未确认，执行前须核对实际输入行 ID、缓存和候选人口。Q64 缓存亦不符合严格非对称比较的计数上限，不能用统一等级排序自动替代目标判定。

后续端到端验证另行定义组合查询和计划集合，评价估计及规划成本是否被实际执行收益抵消。SemCEB 单算子估计高分本身不证明优化有效。若廉价估计已足以选择计划，不自动升级为训练或更复杂的 catalog。
